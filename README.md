# CURIO

**Explore. Learn. Remember.**

CURIO is a platform for structured, progressive learning. You build learning paths, read lessons with their sources attached, and keep a personal knowledge library of what you have learned.

**Status:** planning. No application code exists yet. Everything under [`docs/`](docs/README.md) is a proposal waiting for sign-off.

Start with [`docs/00-critical-review.md`](docs/00-critical-review.md). It lists the risks, contradictions and open questions to settle before implementation begins.
